One timestamp, not three

The station bars briefly carried AS OF hh:mm as well, on the grounds that the hero's countdown is measured from it. But the masthead already says it for the whole board, and the same minute printed three times on one screen reads as a fault rather than as care.

3mm at the edges

The sides always had ~6mm from MARGIN; the top and bottom had none, which made the masthead and the footer line look like they ran off the board. 13px is 3mm at this panel's ~4.45 px/mm. It is a true bleed margin — the masthead's yellow field stops at it rather than running to the edge — so the board reads as a printed sheet rather than as artwork that got cropped.

The 26px it costs comes out of the trains panel, the only one with slack: a block goes 244 → 231 and a row 36 → 33, neither of which is visible.

Where the hourly strip went

There was a temperature curve at y=608 — “next 10 hours”, 170px. It paid for the second station: at 159px each, a block held one emphasised departure and two rows, under an hour of look-ahead when the fetch already asks the API for two. Each block is now 231px — a hero and up to four rows, the whole window.

It was also the weakest panel here. “Will it be colder at 10pm” is not a question anyone in a hallway holding a coat is asking, and the fetch is cheaper without it: those arrays were 96 floats per variable against 4 for a daily one, and losing them takes the heap pressure off a parse that used to truncate.

Four rows, not five

West Dulwich shows four because it is half-hourly — a 120-minute window really does hold four northbound services. The hero keeps a fixed height and whatever follows divides the rest, so late at night the rows just get taller rather than the block shrinking and moving everything under it.

What the four inks do

Black is structure and every value you read. Red is exceptions only — here just the 18:20, running a minute late. Yellow is fields and accents, never alone, because yellow on white is the weakest contrast pair the panel has.

Halftones are the trick that makes four inks feel like more: a yellow/white checkerboard reads as pale gold, black/white as grey. The lattices are keyed to absolute screen coordinates, so they don't shift between the five horizontal bands GxEPD2 renders in.

Northbound only

The API has no direction field, so direction is a destination list. West Dulwich is clean — everything towards town terminates at Victoria. Tulse Hill needs a list, because Thameslink runs through to Bedford while Southern terminates at London Bridge.

Colour caveat

The firmware writes 0xF800 and 0xFFE0, but Spectra pigment renders a muted brick and a mustard, and "white" is a warm grey. The default view uses the real pigments; the toggle shows what the code nominally asks for.
